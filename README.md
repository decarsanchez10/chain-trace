# ChainTrace

ChainTrace is an IoT-enabled Chain-of-Custody verification and tracking system anchored on Bitcoin Cash (BCH).

## Project Structure

- `backend/`: Django project with REST API & BCH anchoring service.
- `frontend/`: Vue 3 + Vite web application & dashboard.
- `firmware/`: ESP32 C++ firmware (Arduino / PlatformIO).
- `hardware/`: KiCad PCB schematic, layout, and gerber files.
- `docs/`: Thesis documentation and architectural diagrams.
