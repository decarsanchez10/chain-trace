# Project Proposal: ChainTrace

## Overview
ChainTrace is an end-to-end chain of custody tracking system using ESP32 IoT hardware, Django REST backend, and Bitcoin Cash (BCH) blockchain anchoring for immutable data integrity.

## Objectives
1. Provide tamper-evident logging of asset handoffs.
2. Store cryptographic hashes of custody events on-chain (BCH OP_RETURN).
3. Offer an accessible web interface for verification and audit trail viewing.
